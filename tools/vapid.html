Notification keys

Makes the key pair Friends uses to send notifications. The keys are made on this device and never sent anywhere.

Public key: put this in js/config.js as VAPID_PUBLIC_KEY and as the Supabase secret VAPID_PUBLIC_KEY.


    
Private key: only goes into the Supabase secret VAPID_PRIVATE_KEY. Never put it in the repository.

    

    
Make keys once. If you make new ones later, everyone has to turn notifications on again.
